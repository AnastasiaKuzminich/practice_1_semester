# Автоматизация подбора букетов

Назначение проекта: автоматизация подбора букетов в
цветочном магазине. Инструмент позволяет управлять списками типов
цветов и их совместимостей, а также находить все возможные букеты в
рамках заданного бюджета с учётом обязательного типа и совместимости
цветов.

## Возможности
1. Чтение данных из бинарных файлов и запись в соответствующие
структуры данных; 
2. Просмотр 2 списков (и предшествующий этому выбор списка, 
который должен быть отображен); 
3. Сортировка списков в соответствии с выбранным критерием
сортировки; 
4. Поиск данных с использованием фильтров; 
5. Добавление данных в список (и предшествующий этому выбор
списка, который должен быть дополнен); 
6. Удаление данных из списка (и предшествующий этому выбор
списка); 
7. Редактирование данных (и предшествующий этому выбор списка, 
данные в котором будут изменены); 
8. Составление всевозможных букетов в пределах заданной суммы, 
с учетом введенного количества типов цветков и обязательного типа
цветка (должен присутствовать в нечетном количестве), в которых все
типы являются попарно совместимыми. Если составление букета
невозможно, то вывод сообщения об этом и составление букета с
меньшим, но максимально возможным, количеством типов (или вовсе
сообщение о невозможности составления букета). Вывод состава и
приблизительной стоимости каждого букета; 
9. Выход из программы без сохранения изменений; 
10. Выход из программы с сохранением изменений (перезапись
бинарных файлов данными из соответствующих динамических
структур).

## Алгоритм подбора букета
Программа составляет всевозможные букеты, удовлетворяющие условиям:

1. Общая стоимость не превышает заданный бюджет
2. Указано количество типов цветков в букете
3. Обязательный тип цветка присутствует **в нечётном количестве**
4. Все типы цветков в букете **попарно совместимы**

Если составить букет с заданными параметрами невозможно, программа:
- выводит соответствующее сообщение;
- пытается составить букет с меньшим, но максимально возможным количеством типов;
- либо сообщает о полной невозможности составления букета.

Для каждого найденного букета выводится состав и приблизительная стоимость.

## Технологии

- **Язык:** C
- **Среда разработки:** Visual Studio Code
- **Компилятор:** GCC
- **Формат данных:** бинарные файлы (`.bin`)
- **Структуры данных:** связные списки
